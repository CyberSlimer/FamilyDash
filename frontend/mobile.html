Calendars

Where do I find my feed URL?

  • Google Calendar — Settings → choose calendar → Integrate calendar → Secret address in iCal format. Type: ICS.
  • iCloud — Type CalDAV, URL https://caldav.icloud.com, your Apple ID and an app-specific password.
  • Outlook / Office 365 — Settings → Calendar → Shared calendars → Publish → copy the ICS link.
  • Any webcal:// subscribe link works as ICS.
